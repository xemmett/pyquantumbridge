Detailed Description

Structure defining information about a tracked target.
Each tracked marpa target maintains one of these structures.
SOG and COG are required to Maintain True data.
If SOG and COG not available then TargetTrueDataValid is set to false.
TrueTargetSped_mps and TrueTargetCourse_degs are only valid if SOG and COG are present.
Notifications are sent to MarpaDataChanged callback function.
