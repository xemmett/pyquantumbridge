SDK and API for Quantum Radar
Introduction to the Quantum SDK and API

The Quantum SDK is a library of functions providing an interface between a Client Application and the Quantum Radar.
The API provides callback functions giving the current status of the Radar, Spoke Data, Marpa Target Data and Alarm information.
The API also allow messages to be sent to the Quantum Radar to control the Radars Parameters and Settings.
The SDK provides example programs that are compiled and ready to run.
The example programs have been built using Visual Studio 2017 and the solution files and source code are supplied with the SDK.
The example source code may be re-used and/or modified for third party applications.

Network Settings

IP Address

The Quantum Radar works with an IP address in the range 10.0.x.x to 10.31.x.x with a subnet mask opf 255.224.0.0

DHCP Server

The IP address is assigned to the Quantum Radar by a DHCP server, the host system must therefore run a DHCP server.

Quantum Protocol

The protocol between the host system and the Quantum Radar allows for multiple displays to control and display data from the Radar.
When a host sends a command to the Radar to change a parameter, it must receive the appropriate notification message to validate that the parameter has been set correctly.
This validation process will ensure the integrity of settings between the Quantum Radar and all connected host systems.
