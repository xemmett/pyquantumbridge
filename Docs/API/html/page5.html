Debugging the Quantum Library

Debug Options

Debug Configuration File

The Debug information can be configured from a configuration file QuantumLibDebug.cfg which should be placed in the directory with the QuantumLib.DLL and the application executable file.
The configuration file allows output to be directed to the console or a file.
The level of debug output may also be specified.
Example QuantumLibDebug.cfg File.
Filename: QDebug.Txt
Output: 3
Level: 2

Debug Output

Debug output can be directed to one of three possible output devices.
0 - No Output
1 - Output to console window in a Win32 console application
2 - Output to console tab in visual studio
3 - Output to file

Debug Level

Debug output can be configured to provide different levels of configuration information. 6 levels of debug output are provided, Level 1 giving the most concise debug information and level 6 the most verbose.
0 - No debug messages are output.
1 - Failure and Error messages, can't create class, sockets ...
2 - Ethernet Messages, creating threads, opening sockets, binding ports ...
3 - Control parameter messages sent to radar
4 - Marpa and Alarm Notification messages
5 - Received System Packets Unit Info, Service Info
6 - Received Radar Packets, logs the serial number and message Id for all messages received from the Radar
