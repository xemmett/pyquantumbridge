Detailed Description

This structure specifies the parameters for a Guard Zone or an Auto Acquire Zone.
A zone is specified as an inner and outer range and a start and end bearing.
The start and end bearing are defined in degrees from the Own Ships Heading in a clockwise direction 0 to 360 degrees.
When setting a Guard Zone or Auto Acquire Zone the 'Enable' parameter is always set to 'true'.
When setting a Guard Zone or Auto Acquire Zone the 'Id' parameter is defined by the value of eSetting_t. (eSettingGuardZone1, eSettingGuardZone2, eSettingAutoAccquireZone1, eSettingAutoAccquireZone2). Guard Zones and Auto Acquire Zones should be enabled and disabled using the GuardZoneEnable and AutoAcquireZoneEnable messages.
