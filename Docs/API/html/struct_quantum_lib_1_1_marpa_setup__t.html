Detailed Description

Parameters for generating dangerous target alarms.
A target is marked as dangerous for the following conditions.
If Targets relative speed is towards own vessel and Target is currently in safe zone.
If Targets relative speed is towards own vessel and CPA is within in the 'SafeZoneDistance' and TCPA is less than the 'TimeToSafeZone'.
If Targets relative speed is towards own vessel and Target is within the 'SafeZoneDistance' after 'TimeToSafeZone' seconds. (Target will not its CPA until after TimeToSafeZone seconds)
