SettingData_t

Using SettingData_t to control the scanner

To send a command to the scanner, the SettingData_t structure should be created by calling the SettingData_t constructor with the setting value and the serial number of the scanner.
The SetValue() method of the SettingData_t structure should then be called with the appropriate type.The SetValue() method contains a number of overloaded functions and verifies the parameter type against the setting supplied in the constructor.
The IsValid() method of the SettingData_t structure will return false if the Setting and Value do not match.
For Example, to set the Radar(with SerialNumber 0x12345678) to Transmit Mode
SettingData_t Setting(eRadarMode, 0x12345678);
Setting.SetValue(eRadarModeTransmitting);
If(Setting.IsValid() == true)
{
bool ret = QuantumLib::API::NewScannerSetting(Setting);
}

Using SettingData_t to receive notifications from the scanner

The SettingData_t structure is by the application program to receive setting change notification messages from the library.
The GetSetting() method of the SettingData_t structure can be used to determine the setting.
The GetValue() method of the SettingData_t structure should then be called with the appropriate type to read the new setting value.The GetValue() method contains a number of overloaded functions and verifies the parameter type against the setting.
The IsValid() method of the SettingData_t structure will return false if the GetValue() method has been called with a type that does not match the setting.
For example
void QuantumApp::SettingChanged(QuantumLib::SettingData_t& rSetting)
{
If(rSetting.GetSetting() == QuantumLib::eSettingRadarMode)
{
QuantumLib::eRadarMode_t RadarMode;
rSetting.GetValue(RadarMode);
If(rSetting.IsValid() == true)
{
// update application with new RadarMode value
}
else
{
// log error
}
}
}
