Detailed Description

Speicfy the alarm Id and/or type to cancel.
Alarms may be cancelled individually, by alarms type or all alarms.
For Example -
Using the Id and Type from the alarm list, cancels an individual alarm.
Setting Id = 0xFFFFFFFF and Type = eAlarmTypeMarpaDangerousTarget cancels all dangerous Target alarms.
Setting Id = 0xFFFFFFFF and Type = eAlarmTypeAll cancels all alarms.
