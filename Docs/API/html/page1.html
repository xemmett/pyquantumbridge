Example Programs

Building the examples

There are three example programs supplied with the Quantum SDK.
The applications have been built using Visual Studio 2017 for win32 and x64.
QuantumClient - windows console based application showing notification messages from the scanner and allowing user modification of settings from a command line interface.
QuantumClientDialog - windows application showing notification messages from the scanner, alarm messages, marpa data and allowing user modification of settings from a command line interface.
QuantumClientPPI - windows based application that can display a PPI image using DirectX 9.

32 bit versions of the Compiled library files and compiled versions of the example programs are installed at : -
{InstallDir}/Ouput/Debug_Win32
{InstallDir}/Ouput/Release_Win32

64 bit versions of the Compiled library files and compiled versions of the example programs are installed at : -
{InstallDir}/Ouput/Debug_x64
{InstallDir}/Ouput/Release_x64

NOTE:
Installation of the x86 version of the Microsoft VC redistribution libraries may be required to run the Win32 example programs.
Installation of the x64 version of the Microsoft VC redistribution libraries may be required to run the x64 example programs.
Installation of the DirectX redistribution libraries may be required to run the Win32 PPI example programs.
There is no 64 bit version of the PPI example program.

Command Line

The command line interpreter is a basic command line allowing the user to set radar parameters

Syntax

<ScannerIndex>, <Setting>, <param1> [,param2, .... ,<paramn>]
All values entered are numerical where
<ScannerIndex> is the index of the scanner that is shown in the Scanner List window
<Setting> is the enumerted value of the setting from e_Setting_t
<param1 .. n> value(s) to sent with the command

Examples

0,1,1 ; Set Radar Mode to 1 (transmitting)
0,1,0 ; Set Radar Mode to 0 (standby)
0,20,5 ; set range index 5 (1/2 nm range)
0,22,0 ; set Gain Mode Manual
0,23,90 ; Set Gain value 90%
0,62,750,175 ; acquire marpa target at 750 metres, bearing 175 degrees
