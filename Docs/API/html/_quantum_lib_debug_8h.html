Detailed Description

Enables Debug Output from QuantumLib DLL.
Debug Output can be directed to a console window (using printf), Visual Studio Output Window (using OutputDebugString) or File (using fprintf).
Debug Output is directed using the enumerted type eDebugOutput_t.
The level of output can also be configured enumerated type eDebugLevel_t.
By default Debug Output is turned off .
Configuration File QuantumLibDebug.Cfg has the following format.
Filename: QuantumLibDebugOutput.Txt
Output : 0
Level : 0
