◆ eDopplerMode_t

enum QuantumLib::eDopplerMode_t

Turn Doppler processing ON or OFF.
When Doppler processing is ON, spoke data contains special values to identify approacing or receeding targets.
A value of 255 in the spoke data indicates that this sample is an approaching target.
A value of 254 in the spoke data indicates that this sample is an receeding target.

◆ eRadarMode_t

enum QuantumLib::eRadarMode_t

Defines the current Radar operating mode.
Radar can be commanded to Standby, Transmitting, TimedTx or PowerDown Modes.
Sleep, Stalled and SelfTest Fail modes are status only values sent from the Scanner.
From Sleep mode, the display can set the scanner to Standby Mode.
From Stalled and Self Test Failed modes, the display must power cycle the scanner. The scanner can be power cycled by setting PowerDown waiting for the Sleep status and then selecting Standby Mode.
