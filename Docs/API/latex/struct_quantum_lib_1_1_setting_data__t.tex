\subsection{Detailed Description}
The \mbox{\hyperlink{struct_quantum_lib_1_1_setting_data__t}{Setting\+Data\+\_\+t}} structure is used as the interface between the Application and Quantum Library.~\newline
It is used to pass settings to the Quantum Radar and to receive notifications of parameter changes from the Quantum Radar.~\newline
~\newline
To change a value in the scanner, a \textquotesingle{}\mbox{\hyperlink{struct_quantum_lib_1_1_setting_data__t}{Setting\+Data\+\_\+t}}\textquotesingle{} structure should be created by calling the constructor with the scanner serial number and the enumerated setting.
