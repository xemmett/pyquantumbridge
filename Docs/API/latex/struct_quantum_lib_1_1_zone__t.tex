\subsection{Detailed Description}
This structure specifies the parameters for a Guard Zone or an Auto Acquire Zone.~\newline
A zone is specified as an inner and outer range and a start and end bearing.~\newline
The start and end bearing are defined in degrees from the Own Ships Heading in a clockwise direction 0 to 360 degrees.~\newline
When setting a Guard Zone or Auto Acquire Zone the \textquotesingle{}Enable\textquotesingle{} parameter is always set to \textquotesingle{}true\textquotesingle{}.~\newline
When setting a Guard Zone or Auto Acquire Zone the \textquotesingle{}Id\textquotesingle{} parameter is defined by the value of e\+Setting\+\_\+t. (e\+Setting\+Guard\+Zone1, e\+Setting\+Guard\+Zone2, e\+Setting\+Auto\+Accquire\+Zone1, e\+Setting\+Auto\+Accquire\+Zone2). Guard Zones and Auto Acquire Zones should be enabled and disabled using the Guard\+Zone\+Enable and Auto\+Acquire\+Zone\+Enable messages.~\newline
