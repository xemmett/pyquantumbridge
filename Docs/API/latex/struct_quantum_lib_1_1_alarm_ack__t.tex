\subsection{Detailed Description}
Speicfy the alarm Id and/or type to cancel.~\newline
Alarms may be cancelled individually, by alarms type or all alarms.~\newline
For Example -\/ ~\newline
Using the Id and Type from the alarm list, cancels an individual alarm.~\newline
Setting Id = 0x\+F\+F\+F\+F\+F\+F\+FF and Type = e\+Alarm\+Type\+Marpa\+Dangerous\+Target cancels all dangerous Target alarms.~\newline
Setting Id = 0x\+F\+F\+F\+F\+F\+F\+FF and Type = e\+Alarm\+Type\+All cancels all alarms.~\newline
