\subsection{Detailed Description}
Parameters for generating dangerous target alarms.~\newline
A target is marked as dangerous for the following conditions.~\newline
If Targets relative speed is towards own vessel and Target is currently in safe zone.~\newline
If Targets relative speed is towards own vessel and C\+PA is within in the \textquotesingle{}Safe\+Zone\+Distance\textquotesingle{} and T\+C\+PA is less than the \textquotesingle{}Time\+To\+Safe\+Zone\textquotesingle{}.~\newline
If Targets relative speed is towards own vessel and Target is within the \textquotesingle{}Safe\+Zone\+Distance\textquotesingle{} after \textquotesingle{}Time\+To\+Safe\+Zone\textquotesingle{} seconds.
