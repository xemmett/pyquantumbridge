\subsection{Detailed Description}
Structure defining information about a tracked target.~\newline
Each tracked marpa target maintains one of these structures.~\newline
S\+OG and C\+OG are required to Maintain True data.~\newline
If S\+OG and C\+OG not available then Target\+True\+Data\+Valid is set to false.~\newline
True\+Target\+Sped\+\_\+mps and True\+Target\+Course\+\_\+degs are only valid if S\+OG and C\+OG are present.~\newline
