\subsection{Detailed Description}
Enables Debug Output from \mbox{\hyperlink{namespace_quantum_lib}{Quantum\+Lib}} D\+LL.~\newline
Debug Output can be directed to a console window (using printf), Visual Studio Output Window (using Output\+Debug\+String) or File (using fprintf).~\newline
Debug Output is directed using the enumerted type e\+Debug\+Output\+\_\+t.~\newline
The level of output can also be configured enumerated type e\+Debug\+Level\+\_\+t.~\newline
By default Debug Output is turned off .~\newline
Configuration File Quantum\+Lib\+Debug.\+Cfg has the following format.~\newline
Filename\+: Quantum\+Lib\+Debug\+Output.\+Txt~\newline
Output \+: 0~\newline
Level \+: 0~\newline
