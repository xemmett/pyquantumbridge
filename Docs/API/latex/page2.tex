The Quantum Library is wrapped inside the \mbox{\hyperlink{namespace_quantum_lib}{Quantum\+Lib}} namespace which includes an \mbox{\hyperlink{class_quantum_lib_1_1_i_notify}{Quantum\+Lib\+::\+I\+Notify}} and \mbox{\hyperlink{class_quantum_lib_1_1_a_p_i}{Quantum\+Lib\+::\+A\+PI}} classes.~\newline
The Client Application class should be derived from the base class \mbox{\hyperlink{class_quantum_lib_1_1_i_notify}{Quantum\+Lib\+::\+I\+Notify}}.~\newline
The Application should first call \mbox{\hyperlink{class_quantum_lib_1_1_a_p_i_a6be3553bb420e8f804d1ea652273cc99}{Quantum\+Lib\+::\+A\+P\+I\+::\+Open()}} to initialise the D\+LL and Ethernet Interface.~\newline
The Application should then call \mbox{\hyperlink{class_quantum_lib_1_1_a_p_i_ad63c6415fc479338caecd97f05c06b02}{Quantum\+Lib\+::\+A\+P\+I\+::\+Register\+For\+Scanner\+Notifications()}} to receive callbacks from the library.~\newline
The methods defined in \mbox{\hyperlink{class_quantum_lib_1_1_i_notify}{Quantum\+Lib\+::\+I\+Notify}} are virtual functions with an empty function body defined. Therefore, these methods may be overrideen by the Client application , but do not need to be implemented.~\newline
When the application and scanner are first connected, the \mbox{\hyperlink{class_quantum_lib_1_1_i_notify_aa7224861ce088af10d5b471d9550bb21}{Quantum\+Lib\+::\+I\+Notify\+::\+Setting\+Changed()}} method will be called for each Setting in the Radar, giving the Client Appplication a full list of the current scanner settings.~\newline
The Client Application can alter the Scanner Settings by making a call to \mbox{\hyperlink{class_quantum_lib_1_1_a_p_i_a9102a0ac0ca44b4d4f7a677e48b3d277}{Quantum\+Lib\+::\+A\+P\+I\+::\+New\+Scanner\+Setting()}}. Each change of scanner setting will generate a callback to \mbox{\hyperlink{class_quantum_lib_1_1_i_notify_aa7224861ce088af10d5b471d9550bb21}{Quantum\+Lib\+::\+I\+Notify\+::\+Setting\+Changed()}} method.~\newline
Some settings may cause multiple callbacks to be generated e.\+g. changing the range index.~\newline
